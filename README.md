# Kit's 30th · Save the date

A one-page save the date for Kit's 30th in Verbier & Cabane Mont Fort (Saturday 27 February – Tuesday 2 March 2027).

After the drawn intro, the title steps through "2,457m", "1st March 2027" and "Kit's 30th" before the details fade in. The phrases live in `PHRASES` near the top of the script in `index.html`.

## Publish on GitHub Pages

1. Create a new repository and upload everything in this folder (`index.html` and the `media` folder) to its root.
2. In the repository, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, pick `main` and `/ (root)`, then save.
3. After a minute the page is live at `https://<your-username>.github.io/<repo-name>/`.

## What's in `media`

- `intro-*.webm` / `intro-*.mp4`: the 11-second drawing (whiteout to sunset), in landscape and portrait versions
- `loop-*.webm` / `loop-*.mp4`: the short loop that plays once the intro has finished
- `poster-*.jpg` / `final-*.jpg`: the first and last frames, shown while the video loads and for visitors who prefer reduced motion
